# KN-RAI-Stanowisko-do-diagnostyki-sprezyn-gr-2
Repozytorium projektu w ramach działalności Koła Naukowego Robotyka Automatyka Informatyka (RAI) na Politechnice Poznańskiej. Opracowanie automatycznego układu do pomiaru charakterystyki sprężyn, który pozwala wyznaczyć zależność siła-ugięcie,  klasyfikować sprężyny na prawidłowe i uszkodzone oraz wizualizować dane na panelu HMI.
